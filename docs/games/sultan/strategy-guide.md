# 《苏丹的游戏》策略攻略整理

> 整理日期：2026-07-26  
> 适用范围：基础机制、资源规划、苏丹卡处理和事件分配。不同版本可能调整事件条件与数值，请以当前游戏内提示为准。  
> 剧透提示：本文前半部分尽量避免剧情剧透；“高品级苏丹卡准备”一节会提到部分事件和角色路线。

## 1. 游戏的核心不是“见事件就做”

《苏丹的游戏》本质上是带期限的卡牌资源分配游戏：

- 当前苏丹卡通常必须在七天内处理，否则推进下一天时可能触发处刑。
- 人物、装备、金币、情报、思潮和苏丹卡都会竞争有限的事件槽位。
- 一个事件可能执行数天；提交后，放入其中的人物和物品在执行期间通常不能移动。
- 同一张卡可能符合多个事件，但不同用法的即时收益、剧情价值和未来机会成本不同。
- 正确决策单位不是“这张卡能不能放”，而是“今天所有卡牌如何分配，整体收益最高且不会破坏未来计划”。

因此，每天都应先观察全部可见事件，再决定卡牌分配，最后才推进下一天。

## 2. 苏丹卡基础

### 2.1 类型

苏丹卡主要分为四类：

- 杀戮：通常要求死亡、决斗、献祭或其他暴力行为。
- 纵欲：通常要求符合品级和条件的角色或场所。
- 征服：通常对应狩猎、战斗、镇压或军事目标。
- 奢靡：通常通过消费金币、建设或购买昂贵物品处理。

### 2.2 品级

卡牌和目标通常分为石、铜、银、金四个品级。

- 苏丹卡只能用于满足品级要求的目标。
- 能处理高品级苏丹卡的目标，往往也能处理同类型的低品级卡。
- 这不代表低品级卡应该随意投入高价值事件：高品级目标通常更稀缺，应考虑留给更难处理的卡。
- 金卡机会少、准备成本高；社区攻略普遍认为金征服尤其容易因准备不足造成困局。
- 运行时 Agent 以 `cardTier` 映射及事件槽位内置卡为上下文做软评分；合法向下兼容不会被硬拦截。

### 2.3 七天期限与换卡

- 右上角处刑倒计时反映当前苏丹卡的剩余期限。
- 在最后一天仍未处理卡牌时，点击下一天可能直接导致死亡。
- 牌盒可用于查看卡序和交换当前苏丹卡；交换不会重置当前处刑倒计时。
- 换掉低品级卡存在抽到难处理金卡的风险，不能把换卡当作无成本操作。

## 3. 事件与仪式界面

事件和仪式是卡牌投入与收益结算的主要场所。

- 红色数字通常表示事件还会在地图上保留多少回合。
- 蓝色数字通常表示提交后需要执行多少回合。
- 事件到期后，可能消失、刷新或按当前状态直接结算。
- 执行中的卡牌会被锁定；如果仍未推进下一天，可以使用扫帚清除提交并重新安排。
- 槽位条件并不统一，可能要求人物、物品、苏丹卡、特定标签、属性、品级或剧情状态。

提交前至少检查：

1. 这是限时机会还是可重复、可长期保留的事件？
2. 会锁定哪些人物和物品，持续几天？
3. 是否存在更便宜的替代卡？
4. 是否占用了另一个关键事件所需的唯一人物、装备或情报？
5. 事件结果是确定收益、骰子检定，还是可能推进不可逆剧情？

## 4. 每日推荐决策流程

### 第一步：检查硬期限

依次检查：

- 当前苏丹卡剩余天数。
- 即将消失的限时事件。
- 已执行事件的结算时间。
- 可能造成死亡、处刑或关键剧情失败的任务。

生存与强制期限高于普通资源收益。

### 第二步：盘点当天全部机会

不要打开一个事件就立即提交。先查看：

- 所有可见事件及其槽位。
- 每张手牌可进入哪些事件。
- 哪些人物、装备和消耗品被多个事件同时需要。
- 哪些事件可以留到以后，哪些今天不用就会消失。

### 第三步：比较完整分配方案

至少比较两到三个完整方案，而不是只评价单个动作。

示例：

- 方案 A：高属性角色用于限时剧情，普通角色治理家业。
- 方案 B：高属性角色用于高收益经济事件，但放弃限时剧情。
- 方案 C：暂不执行低收益事件，保留角色和情报应对即将到期的苏丹卡。

比较时按以下优先级：

1. 避免死亡、处刑和关键任务超时。
2. 处理当前或即将难以处理的苏丹卡。
3. 抓住不可重复的限时剧情和高价值窗口。
4. 推进能产生长期能力、盟友或固定收益的路线。
5. 获取金币、情报、书籍和普通属性成长。
6. 保留稀有人物、通用装备与高品质消耗品的未来选择权。

### 第四步：逐个提交并验证

- 每提交一个事件，都重新检查剩余手牌和可见事件。
- 如果提交后发现更好的安排，在推进下一天前使用扫帚清除提交并重新分配。
- 不要因为某个事件“可以提交”就默认它“值得提交”。

### 第五步：最后才进入下一天

只有在以下条件满足后才推进：

- 没有必须处理的限时事件。
- 没有还能产生明显收益的空闲人物或资源。
- 当前苏丹卡期限安全。
- 已执行事件不会造成未预期的关键资源冲突。
- 保留卡牌确实具有更高未来价值，而不是单纯遗漏操作。

## 5. “销卡队列”策略

英文社区攻略将可长期保留、不会轻易过期或可重复召回的销卡事件称为 **Break Queue**，本文译为“销卡队列”。

核心思路：

- 不要看到销卡事件就立刻消耗。
- 将稳定、低风险的销卡事件保留，作为未来抽到困难苏丹卡时的安全出口。
- 优先利用即将过期的随机事件处理低品级卡，避免浪费长期稳定入口。
- 银卡事件往往更随机、更容易带期限，出现匹配窗口时应提高优先级。
- 金卡入口非常稀缺，应提前建设路线，不能只在抽到金卡后才开始寻找方法。

销卡队列让玩家能把更多日常行动投入经济、成长和剧情，而不是每周临时寻找苏丹卡出口。

## 6. 卡牌机会成本

### 6.1 人物卡

人物不仅提供属性，也可能是：

- 剧情路线的唯一参与者。
- 上朝提供支持、金币或情报的固定人选。
- 多日战斗或检定的核心成员。
- 特定结局所需盟友。

不要只根据当前骰子数量选择人物。将关键人物锁定数天，可能比少拿一次资源的代价更大。

### 6.2 装备与物品

- 合适装备可能直接提高骰子数量或改变检定结果。
- 部分物品能跳过检定或满足特殊槽位。
- 消耗品使用后会消失，应比较“提高当前成功率”和“保留给更困难事件”的价值。
- 书籍更适合用于长期培养，不应仅作为普通槽位填充物。

### 6.3 情报

- 情报可以提高相关属性并提供重骰。
- 银级情报具有较高的困难检定价值。
- 普通事件中为了轻微收益消耗高品质情报，通常机会成本较高。

### 6.4 苏丹卡

苏丹卡既是死亡期限，也是特殊事件的通行证。

- 不能只追求尽快销毁；某些限时事件可能让同一张卡产生更好的剧情或资源结果。
- 也不能无理由拖到最后一天；拖延会压缩处理意外事件的空间。
- 比较“现在安全处理”和“等待更优窗口”的风险收益。

## 7. 常驻活动的战略用途

### 治理家业

- 是稳定金币来源。
- 中文和英文攻略都提到，较高的智慧与社交组合能提高骰子和金币收益。
- 社区资料给出的收益为：0 骰约 1 金币、1 骰约 2 金币、2 骰约 3 金币、3 骰及以上约 5 金币；版本变化时应以游戏实际结算为准。
- 这是空闲人物的常见去向，但不应挤占限时剧情所需角色。

### 浴场

- 是情报与随机事件的重要来源。
- 更高的魅力与社交通常提高情报品质。
- 可生成处理石、铜苏丹卡的事件，是构建销卡队列的重要地点。
- 银级情报适合保留给关键检定。

### 权力的游戏（上朝）

- 需要关注支持与反对，避免谗言累积。
- 贵族或追随者可能提供支持、情报或其他收益。
- 上朝也提供部分纵欲、杀戮苏丹卡的处理机会，但次数与目标可能有限。
- 不能为了日常收益过早消耗关键人物或不可重复的销卡机会。

### 书店与阅读

- 书籍用于长期提升人物属性，能降低后续困难检定的成本。
- 早期建立专精人物通常比平均培养所有人更有效。
- 买书和阅读会占用金币、人物与回合，应与当前七天期限协调。

### 俺寻思

- 将特定卡牌拖入左下角骷髅可以发现相关事件或提示。
- 书籍、金币、情报、人物和苏丹卡都可能触发不同内容。
- 它适合用于发现未知用途，但不应替代对当前全部事件的整体规划。

## 8. 骰子与风险管理

- 攻略资料称每颗骰子的基础成功率约为三分之一。
- 骰子数量通常由人物属性、对抗方属性、装备和消耗品共同决定。
- 多属性事件可能采用属性合计，也可能分别进行多次检定。
- 情报等卡牌可以增加属性或提供重骰。
- 失败不一定等于事件完全失败，但可能得到较差结果或进入不同分支。

决策时应区分：

- 必须成功：死亡、处刑、不可逆关键剧情。
- 可以承担失败：可重复经济活动、普通情报获取。
- 信息不足：先保留高价值消耗品，或利用可回溯难度获取更多信息。

不要只最大化期望收益；关键任务应优先控制最坏结果。

## 9. 高品级苏丹卡准备（含轻度剧透）

### 金征服

- 社区攻略普遍认为它是最难稳定处理的卡之一。
- 相关机会往往依赖长期剧情、军队、高恶名/权势条件或特定角色路线。
- 应从前期开始保留征服路线、战斗人才和相关剧情入口。

### 金奢靡

- 通常需要大量金币、地产建设或昂贵购买机会。
- 保持稳定现金流比抽到卡后临时赚钱更可靠。
- 部分建设只能使用一次，不要用低品级卡浪费高品级出口。

### 金纵欲

- 特定高品级角色、激情关系、宫廷或欢愉之馆路线可以处理。
- 同一角色或同一地点可能只能有效处理有限次数，不能把已有成功路径视为无限资源。

### 金杀戮

- 高品级目标和合理后果都很稀缺。
- 过早杀死重要角色可能切断任务线。
- 决斗等路线可能附带高强度战斗和新的七天期限，提交前必须确认战斗能力。

### 通用保底

英文 Wiki 攻略提到：

- 高声望的教会路线可以重置期限或处理一张困难苏丹卡。
- 某些后期剧情可以处理任意类型苏丹卡。

这些能力属于稀缺保底资源，优先用于最难处理的金卡，而不是普通石、铜卡。

## 10. 常见误区

- 看到槽位能放就立即提交，没有比较其他事件。
- 用最强人物完成低风险日常任务，导致限时剧情无人可用。
- 用银级情报或稀有装备换取很小的即时收益。
- 用低品级苏丹卡消耗只能使用一次的高品级目标。
- 把所有稳定销卡事件立即做完，未来抽卡时失去安全出口。
- 只看事件消失期限，不看执行耗时和卡牌锁定。
- 拖到最后一天才寻找销卡方法，没有为随机事件留出缓冲。
- 在仍有高价值行动时直接进入下一天。
- 将简单难度回溯当作正常资源，形成无法迁移到其他难度的策略。

## 11. 给 VibeSultan Agent 的决策原则

Agent 每天应建立一次全局分配视图：

1. 收集全部可见事件、槽位条件、剩余时间和执行耗时。
2. 枚举每张卡可以进入的事件与槽位。
3. 标记人物、装备、物品和苏丹卡之间的互斥占用。
4. 生成多个完整分配方案，而不是逐槽贪心。
5. 先按生存和期限过滤，再比较剧情、长期收益和资源收益。
6. 对稀有卡、通用卡和唯一剧情角色计算机会成本。
7. 每执行一个动作后重新观察；状态变化时重新规划。
8. 只有确认当天没有更高价值方案时才执行 `next_round`。

建议采用以下分层目标，而不是单一金币评分：

1. 避免游戏结束和硬期限失败。
2. 保证当前苏丹卡存在可行解。
3. 保留未来金卡和关键剧情的必要出口。
4. 抓住不可重复的限时机会。
5. 最大化长期能力、盟友、固定收入和剧情进度。
6. 最大化普通资源收益。
7. 最小化稀有卡消耗与关键人物锁定时间。

## 12. 信息可靠性说明

- 游戏内 UI 和当前版本配置应作为最终事实来源。
- Wiki 的机制说明通常比普通聚合攻略更适合查条件，但仍可能滞后于补丁。
- “销卡队列”、具体事件优先级和金卡路线属于玩家策略，不是唯一正确玩法。
- 英文 Wiki 的专题攻略明确标注部分事件名和个别条件仍需核实；本文没有把这些不确定项写成确定规则。
- 具体角色、事件和结局路线可能包含版本差异，应在 Agent 中记录实际执行结果并持续修正。
